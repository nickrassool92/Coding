Backtest

Each game is predicted using only what was known before kick-off: matches already played plus the season before. The settings were fitted on last season's 380 games and then checked on this season, which the fitting never saw. Missing players aren't included, because past team news isn't available.

Brier score measures how good the win, draw and loss chances were. Lower is better, and 0.667 is the same as guessing.
